# 말봄

실어증 환자를 위한 한국어 읽기 훈련 웹 앱 초안입니다. 로그인·훈련 결과는 **Google Sheets + Apps Script**로 연동합니다. Cloud Console과 서비스 계정 키는 필요하지 않습니다.

**이름과 비밀번호는 관리자 Google 시트의 사용자 탭에서 설정합니다.** B열 이름, C열 새 비밀번호, D열 사용가능 체크, H열 설정 상태를 확인합니다. 최초 권한 승인·웹 앱 배포는 한 번 필요하며 자세한 절차는 `GOOGLE-SHEETS-SETUP.md`에 있습니다.

- 자음·모음 / 단어 / 문장 / 문단 훈련
- 브라우저 한국어 음성인식과 제시문 듣기
- 서버에서 계산한 글자 일치도, 사용자별 기록, 관리자 종합리포트
- 결과 인쇄·CSV 다운로드 및 저장 실패 재시도

v0.5는 로그인 후 **오늘의 학습 / 연습하기**를 고르는 화면으로 시작합니다. **오늘의 학습**은 연결 코스이며, **연습하기**는 자음·모음·단어·문장·문단 중 원하는 영역을 고르는 기존 모드입니다. 소리 3개를 연습하고, 관련 단어 3개를 읽은 뒤, 앞의 단어가 들어간 문장 3개로 이어집니다. 예: 가 → 가족 → 가족과 밥을 먹어요. 오늘의 학습 화면에서는 단계별 경로와 저장 진행률을 확인하며, 연습하기 화면에서는 자음·모음만 따로 연습할 수도 있습니다. 당일 저장한 문항은 다시 로그인해도 이어서 학습하고, 완주한 다음 날에는 다음 연결 코스를 제시합니다. 소리만 연습하거나 개별 영역을 연습한 기록은 하루 코스 진행률에 포함하지 않습니다.

관리자 시트의 I열 연습묶음은 유지합니다. 연결 코스는 묶음별 고정 분량을 사용하며, 이전 영역별 개수(J~M열)로 연결 코스를 자르지는 않습니다. 모든 개수가 0인 휴식 배정은 유지합니다. 문항과 데이터 호환성, 당일 복원 규칙은 `JOURNEY-MODE.md`에 정리했습니다.

화면은 `dist/index.html`입니다. `dist/config.js`에 말봄 Apps Script `/exec` 주소를 설정합니다. `말봄 시작.cmd`는 화면 확인용 정적 서버만 실행합니다. Node.js 22 이상이 있으면 `npm test`로 인증·저장·화면 처리를 검증할 수 있습니다.

GitHub Desktop 배포용 웹 파일은 `docs` 폴더에 준비합니다. **배포 준비.cmd → GitHub Desktop Commit → Push** 순서로 갱신합니다. GitHub Pages에서는 `main` 브랜치의 `/docs`를 게시하도록 설정합니다. 자세한 절차는 `GITHUB-PAGES.md`에 있습니다.

오디오 파일은 저장하지 않습니다. 음성인식된 문장과 글자 일치도는 관리자 시트에 저장되며 임상 평가를 대신하지 않습니다.

홈의 ‘오늘의 학습’은 소리→연결 단어→연결 문장으로 진행하고, ‘연습하기’는 기존 영역별 연습을 제공합니다. 말하기 중에는 인식된 글자를 표시하며, 최종 인식 결과가 제시문과 같으면 결과를 저장하고 자동으로 다음 문항으로 넘어갑니다. 다른 글자로 인식되면 내용을 확인하고 다시 말하거나 ‘이 내용으로 연습 마치기’를 눌러 저장할 수 있습니다. ‘마이크 소리 점검’으로 기기의 오디오 입력을 확인할 수 있으며 점검 소리는 저장하지 않습니다. 마이크 연결 실패·권한 차단·인식 서비스 오류를 구분해서 안내하고, 오류 전 인식된 내용은 확인할 수 있도록 유지합니다.

연습 화면에서는 첫 문항부터 ‘말하기 시작’을 바로 누를 수 있습니다. 마이크 점검의 소리 감지와 글자 인식을 구분해서 안내합니다. 자동 진행은 최종 인식 결과의 일치와 서버 저장 성공을 모두 확인한 뒤 실행하며, 저장 실패·다른 글자 인식·일시정지 시에는 문항을 유지합니다.
