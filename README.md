# 말봄

실어증 환자를 위한 한국어 읽기 훈련 웹 앱 초안입니다. 로그인·훈련 결과는 **Google Sheets + Apps Script**로 연동합니다. Cloud Console과 서비스 계정 키는 필요하지 않습니다.

**이름과 비밀번호는 관리자 Google 시트의 사용자 탭에서 설정합니다.** B열 이름, C열 새 비밀번호, D열 사용가능 체크, H열 설정 상태를 확인합니다. 최초 권한 승인·웹 앱 배포는 한 번 필요하며 자세한 절차는 `GOOGLE-SHEETS-SETUP.md`에 있습니다.

- 자음·모음 / 단어 / 문장 / 문단 훈련
- 브라우저 한국어 음성인식과 제시문 듣기
- 서버에서 계산한 글자 일치도, 사용자별 기록, 관리자 종합리포트
- 결과 인쇄·CSV 다운로드 및 저장 실패 재시도

v0.2는 환자가 혼자 이용하는 흐름으로 구성했습니다. 홈에서 오늘의 연습을 시작하면 소리 → 단어 → 문장을 순서대로 안내합니다. Google 사용자 시트 I~M열에서 연습묶음과 분량을 배정할 수 있으며, 비워두면 소리 2개·단어 3개·문장 2개로 시작합니다. 쉬기·이어하기·건너뛰기를 제공하며 자세한 일치도는 나의 기록 안에서 펼쳐 볼 수 있습니다.

화면은 `dist/index.html`입니다. `dist/config.js`에 말봄 Apps Script `/exec` 주소를 설정합니다. `말봄 시작.cmd`는 화면 확인용 정적 서버만 실행합니다. Node.js 22 이상이 있으면 `npm test`로 인증·저장·화면 처리를 검증할 수 있습니다.

GitHub Desktop 배포용 웹 파일은 `docs` 폴더에 준비합니다. **배포 준비.cmd → GitHub Desktop Commit → Push** 순서로 갱신합니다. GitHub Pages에서는 `main` 브랜치의 `/docs`를 게시하도록 설정합니다. 자세한 절차는 `GITHUB-PAGES.md`에 있습니다.

오디오 파일은 저장하지 않습니다. 음성인식된 문장과 글자 일치도는 관리자 시트에 저장되며 임상 평가를 대신하지 않습니다.
